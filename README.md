# Java Swing Calculator

A lightweight desktop calculator application built in Java using the Swing and AWT libraries. The project demonstrates event-driven programming, custom `ActionListener` implementation, and GUI layout management.

## Features

- **Basic Arithmetic Operations:** Supports multi-digit integer input, addition (`+`), and state reset (`C`).
- **Real-time State Display:** Dynamically updates labels showing the accumulated total (`SUMA`) and the currently entered operand (`NOWA`).
- **Grid-based GUI:** Responsive button layout constructed with `GridLayout`.

## Technologies Used

- **Java** (JDK 17+)
- **Java Swing & AWT** (`JFrame`, `JPanel`, `JButton`, `JLabel`, `GridLayout`, `ActionListener`)

## How to Run

1. Clone the repository:
   ```bash
   git clone [https://github.com/OnlyBart123/Kalkulator.git](https://github.com/OnlyBart123/Kalkulator.git)
   ```
2. Navigate to the `src` directory and compile the source file:
   ```bash
   javac Kalkulator.java
   ```
3. Run the application:
   ```bash
   java Kalkulator
   ```
